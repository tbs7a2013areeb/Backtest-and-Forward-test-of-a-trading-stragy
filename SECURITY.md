# Security Policy

This is a demo project!!!!!

It does not handle user accounts, passwords, payments, or private customer data.
It also does not need API keys because the stock data is downloaded from
`yfinance`.

## Reporting a Problem

If you find a security issue, please open a GitHub issue and explain:

1. What the problem is
2. Where it happens in the code
3. How someone can reproduce it
4. What you think the fix could be

Please do not include real secrets, tokens, or private data in the issue.

## Supported Version

Only the latest version on the `main` branch is maintained.

## Notes

This project is for learning and testing only. It is not financial advice and
should not be used with real money without more review and testing.
